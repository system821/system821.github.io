微信登录流程

微信官方获取手机号信息

微信小程序登录流程中的 code 和 phoneCode 的区别：

参数 名称 用途 获取方式
code 登录凭证 换取 openid 和 session_key wx.login()
phoneCode 手机号授权凭证 换取用户手机号 用户点击授权按钮后获得
对比项 wx.login() 产生的 code getPhoneNumber 产生的 code
作用 获取用户的微信身份（openid） 获取用户的手机号
触发方式 直接调用 wx.login() 这个API 用户点击特殊按钮 open-type="getPhoneNumber" 并授权
前端怎么拿 wx.login({ success: (res) => { res.code } }) 在按钮的回调函数里 e.detail.code
后端去微信换什么 换 openid 和 session_key 换 手机号
两个code能互换吗 不能 不能
  1. 前端调用wx.login()获取code
  2. 后端根据code获取openid

3.这个时候我们就会获取到openid和session_key了，

session_key 是解密这些数据的唯一密钥。开发者需将 session_key 与前端传来的加密数据在服务端解密，才能获取真实的用户信息（如手机号、昵称等）。
openid是当你之后再次以相同的手机号再次登录时，返回的唯一id

4.这个时候一般而言需要通过openid去调用本地数据库 看看有没有当前这个人，如果有，就直接返回数据即可

5.如果没有手机号 前端需要通过getPhoneNumber获取code传给我
